# 🐧 Linux Distro Chooser

A fast, mobile-friendly Linux distro chooser that helps users find the right Linux distribution based on their experience level and use case.  
The app runs entirely in the browser and requires no installation.

---

## 🚀 Live Demo
Once published with GitHub Pages, the app will be available at:

https://Techrefreshing.github.io/linux-distro-chooser/


---

## 📌 Features

- Helps beginners, gamers, developers, and server users choose a Linux distro
- Clean and modern user interface
- Works on desktop and mobile devices
- No backend, no frameworks, no build tools
- Extremely fast and lightweight
- SEO-friendly and GitHub Pages compatible
- Includes links to detailed guides on **techrefreshing.com**

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

No external libraries or dependencies are used.

---

## 📂 How to Use

1. Open the app in your browser  
2. Answer a few simple questions  
3. Get recommended Linux distributions  
4. Click “Read more” to learn about each distro

---

## 🌐 Deploy on GitHub Pages

1. Upload `index.html` to the repository
2. Go to **Settings → Pages**
3. Select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Save

Your site will be live in a few seconds.
